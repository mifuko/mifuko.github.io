“level”、“radar”、“Kayak”、“Madam”、“Racecar”、“Noon”和“12321”都是回文 9. Palindrome Number Given an integer x, return true if x is a palindrome, and false otherwise.

Example 1:

Input: x = 121 Output: true Explanation: 121 reads as 121 from left to right and from right to left. Example 2:

Input: x = -121 Output: false Explanation: From left to right, it reads -121. From right to left, it becomes 121-. Therefore it is not a palindrome. Example 3:

Input: x = 10 Output: false Explanation: Reads 01 from right to left. Therefore it is not a palindrome.

Constraints:

−231<=x<=231−1 -2^{31} <= x <= 2^{31} - 1 −231<=x<=231−1

关键句

假设我们有一个整数 x，我们的目标是得到它的翻转版本，记作 reversed_x。

x % 10：这一步是取 x 的个位数。% 是取余运算符，x % 10 的结果就是 x 除以 10 后的余数，对于任何整数 x，这都将给出其个位上的数字。

(reversed_x * 10) + ...：在开始时，reversed_x 通常初始化为 0。每次循环中，我们先将 reversed_x 左移一位（等效于乘以 10），为添加新的数字到其个位上做准备。

+ (x % 10)：然后，将当前 x 的个位数加到 reversed_x 的末尾。这样逐步构建了 x 翻转后的数字。

核心思路

1、逐位访问的需求： 要反转一个整数，我们需要逐位访问它，这意味着从最低位（个位）开始，一直到最高位。但是，在大多数编程语言中，直接访问整数的某一位并不直接支持，所以我们需要间接方法。

2、取模运算（%）和整除运算（//）的利用：

  • 取模运算（%）：x % 10 可以得到 x 的个位数。这是因为任何整数除以10的余数就是它的个位数。
  • 整除运算（//）：x //= 10 可以去掉 x 的个位数。这实际上是对 x 进行了右移操作，相当于抛弃了当前的个位数，让 x 变成只有高位数字的数。

3、数字构建： 为了构建反转数，每次循环我们都需要把当前的最低位数加到已构建数的末尾。由于数字是以十进制表示的，每向左移动一位，数值就相当于乘以10。因此，我们先将已构建的反转数乘以10，再加当前的最低位数，就能正确地将新位数放置到反转数的末尾。

4、循环终止条件： 选择 while x > 0作为循环终止条件是因为一旦 x 变为0，说明所有的位都已经被处理过了，没有剩余的位需要反转。这也是自然数（正整数）在逐位处理后必然会达到的状态。
