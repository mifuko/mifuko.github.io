Write a function to find the longest common prefix string amongst an array of strings.

If there is no common prefix, return an empty string "".

Example 1:

Input: strs = [“flower”,”flow”,”flight”]
Output: “fl”

Example 2:

Input: strs = [“dog”,”racecar”,”car”]
Output: “”
Explanation: There is no common prefix among the input strings.

Constraints:

  • 1 <= strs.length <= 200
  • 0 <= strs[i].length <= 200
  • strs[i] consists of only lowercase English letters.

solution 1 笨蛋方法

用字符串切片操作

核心思路

  1. 初始化与边界条件处理：首先检查输入的字符串列表strs是否为空，若为空，则直接返回空字符串，因为没有字符串输入自然没有公共前缀可言。

  2. 循环比较字符：

    • 通过一个循环来逐个比较每个字符串中相同位置的字符，用变量idx作为当前比较字符的位置索引。
    • 在每一轮循环开始时，假定所有字符串在当前位置的字符都相同，并初始化current_char用于暂存当前比较的字符。
    • 遍历字符串列表strs中的每个字符串s，检查是否已经到达字符串的末尾（即idx是否等于字符串s的长度）。如果已到达末尾，则意味着不能再向后比较，此时将current_char设置为None。
    • 如果current_char还未被赋值（即首次遇到的字符串中的字符），将其设置为当前字符串s在位置idx的字符。
    • 接着，检查当前字符串s的字符是否与之前记录的current_char相等，如果不等，说明从开始到当前位置的字符序列是所有字符串的公共前缀，于是直接返回这个前缀（即第一个字符串的前idx个字符）。
    • 在遍历过程中，还通过all_reached_end标志判断是否所有字符串都已经比较到了末尾，如果是，则跳出循环。

  3. 返回结果：

    • 若循环正常结束，说明所有字符串在没有找到不匹配字符的情况下就已经比较到了某个字符串的末尾，这时最长公共前缀就是从开始到这个末尾的所有字符，返回第一个字符串的前idx个字符作为结果。

复杂度分析

  • 时间复杂度

  1. 外层循环：对于字符串列表 strs 中的每个字符串，代码执行一次外部循环。最坏情况下，strs 列表中有 N 个字符串，因此外层循环最多执行 N 次。

  2. 内部循环：在内部，通过比较并缩短前缀的过程，实际上是对每个字符串进行了一种“尝试匹配”的操作。每次匹配失败时，前缀长度减1，直至匹配成功或前缀长度减到0。最坏情况下，每个字符串都需要与当前的最长公共前缀进行字符级别的比较，直到找到最长公共前缀或确定无公共前缀。这意味着，对于每个字符串，可能需要进行最多 M 次字符比较，其中 M 是字符串列表中最长字符串的长度。

综上所述，最坏情况下的时间复杂度为 O(N * M)，其中 N 是字符串的数量，M 是字符串中的最大长度。这是因为每个字符串都要可能与最长公共前缀进行比较，而最长公共前缀的长度最大为 M。

  • 空间复杂度

  1. 变量存储：代码中主要使用的额外空间包括存储最长公共前缀的 prefix 变量以及一些控制循环的变量（如循环计数器）。这些存储需求与输入字符串的数量或长度无关，因此这部分的空间复杂度为 O(1)。

  2. 输入参数：虽然 strs 列表作为输入传递给了函数，但是空间复杂度分析通常不考虑输入数据所占用的空间。即便考虑，这部分也是 O(N*M)，因为列表存储了所有的字符串。

整体的空间复杂度主要受到控制变量的影响，可以视为 O(1)，忽略了输入参数所占的空间。这是因为我们的分析重点在于算法运行过程中额外分配的存储空间，而不是输入数据本身的大小。

字符串切片

Python中的字符串切片功能是一个强大而灵活的工具，允许你提取字符串中的连续部分，形成新的字符串。其基本语法是 string[start:end]，其中start和end是索引值，用来指定切片的起始和结束位置。值得注意的是，索引是从0开始的，且end处的字符不包含在切片结果内。如果省略start或end，默认会从字符串的开始或延续到字符串的末尾。

基本用法

  • 提取子串：string[start:end] 从start位置开始提取，直到end - 1位置。
  • 省略起始索引：string[:end] 从字符串的开头提取到end - 1位置。
  • 省略结束索引：string[start:] 从start位置开始提取到字符串末尾。
  • 省略两端索引：string[:] 复制整个字符串。

负索引

Python还支持负索引，-1表示最后一个字符，-2表示倒数第二个字符，以此类推。

  • 从末尾开始提取：string[-n:] 提取字符串的最后n个字符。
  • 到倒数第n个字符：string[:-n] 从开头提取到倒数第n+1个字符前。

solution 2 聪明方法

用zip，但无法通过用例用例 ["ab", "a"]：

用zip，经过修改通过用例用例 ["ab", "a"]：
使用 zip 方法的解决方案在处理用例 [“ab”, “a”] 时可能无法正确返回最长公共前缀，因为 zip(*strs)在较短的字符串用尽字符后会停止，导致它不会检查所有可能的公共前缀。

核心思路

  1. 使用 zip(*strs)：zip 函数将输入的字符串列表按字符位置配对，形如 ('f', 'f', 'f')，这样可以同时检查所有字符串在相同位置上的字符是否相同。

  2. 遍历并检查字符一致性：通过 enumerate 遍历每个字符位置，使用 set(chars) 来检测当前位置上的字符是否全部相同。由于集合(set)会移除重复元素，如果集合的长度大于1，说明至少有两个不同的字符，此时的索引 i 之前的字符串部分就是最长公共前缀。

  3. 返回结果：

    • 如果在某次迭代中发现了不匹配的字符，则立即返回到那个位置为止的前缀。
    • 如果遍历完所有字符位置都没有发现不匹配的字符，说明所有字符串要么完全相同，要么都是其他字符串的前缀，此时返回第一个字符串即可，因为它包含了最长公共前缀。

复杂度分析

  • 时间复杂度: 使用 zip 的方法在最坏情况下遍历所有字符串中每个位置的字符一次，直到找到不匹配的位置。因此，时间复杂度主要取决于输入字符串数组中字符串的总字符数量，假设所有字符串的平均长度为 L，字符串的数量为 N，则时间复杂度为 O(N*L)。在极端情况下，如果所有字符串完全相同且非常长，时间复杂度接近 O(N*M)，其中 M 是字符串的最大长度。

  • 空间复杂度: zip 本身会创建一个迭代器来存储配对的元组，但实际的空间复杂度还取决于如何使用这些元组。在上述寻找最长公共前缀的示例中，如果直接在循环中处理而不显式转换为列表，则空间复杂度较低，主要由循环变量和辅助变量占用，可以认为是 O(1)。但若将 zip 的结果转换为列表（如 list(zipped)），则会额外占用 O(min(N, M)) 的空间，其中 min(N, M) 是字符串数量和最短字符串长度的较小值。
