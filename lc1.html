leetcode小抄：1. Two Sum

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

Example 1:

Input: nums = [2,7,11,15], target = 9 Output: [0,1] Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].

Example 2:

Input: nums = [3,2,4], target = 6 Output: [1,2]

Example 3:

Input: nums = [3,3], target = 6 Output: [0,1]

Constraints:

  • 2 <= nums.length <= 104
  • -109 <= nums[i] <= 109
  • -109 <= target <= 109
  • Only one valid answer exists.

Follow-up: Can you come up with an algorithm that is less than O(n2) time complexity?

solution 1 笨蛋方法

暴力枚举

时间复杂度 (Time Complexity)

对于外层循环，它遍历数组中的每个元素，共有 n 次迭代（其中 n 是数组的长度）。 对于内层循环，每次外层循环迭代时，它会遍历剩余的 n-1, n-2, ..., 1 个元素。因此，总的内循环次数是 (n-1) + (n-2) + ... + 1 = n*(n-1)/2。 所以，总体的时间复杂度为 O(n^2)，表示算法的运行时间与输入大小的平方成正比。当输入数组非常大时，这种方法的效率会变得很低。

空间复杂度 (Space Complexity)

在这个方法中，除了输入数组和少数几个变量（如索引变量 i 和 j）之外，主要的额外空间消耗在于存储找到的解的列表 solution。 在最坏的情况下（即数组中有多对数字满足条件），solution 可能会存储所有这些解对，但由于题目假设只有一个解，我们实际上只需要存储一对索引。因此，在实现中，即使找到多对解，也只保留并返回第一对，这使得额外空间需求为 O(1)，即常数空间复杂度。 然而，如果按照代码直接实现（未提前终止循环并直接返回），它会存储所有满足条件的索引对，此时在多解的情况下，空间复杂度会是 O(m)，其中 m 表示解的总数。

总结来说，此方法的时间复杂度为 O(n^2)，在保证题目假设（恰好一个解）的情况下，空间复杂度为 O(1)；如果不提前终止并存储所有解，则在多解情况下空间复杂度为 O(m)。

solution 2 聪明方法

我们遍历列表一次，对于每个元素，我们可以检查哈希表中是否存在目标值减去当前元素的值。如果存在，说明我们找到了一对解；如果不存在，我们将当前元素存入哈希表以供后续检查。这种方法的时间复杂度为O(n)，更加高效。

时间复杂度

  • 遍历: 我们首先遍历整个列表 nums，这一步的时间复杂度是 O(n)，其中 n 是列表的长度。
  • 查找与检查: 对于每个元素，我们执行一次查找示操作来寻找其补数（即 target - num），并在字典中查找这个补数是否存在以及是否已经记录过相应解对。在最坏的情况下，每次查找都是独立的，且由于我们使用了字典，查找时间平均来说是 O(1)。

因此，总的时间复杂度是 O(n) * O(1) = O(n)。这里的关键是，虽然内部有查找操作，但字典的高效查找使得整体时间复杂度由遍历部分主导。

空间复杂度

  • 字典: 我们使用了一个字典 num_dict 来存储每个数字及其在列表中的位置。在最坏的情况下，这个字典需要存储列表中的每个元素，因此其空间复杂度为 O(n)。
  • 解列表: solutions 列表用于存储所有不重复的配对。在最极端情况下（例如，当 nums 中的每个数字都相同且刚好能配对成目标值时，如本例），可能需要存储 n/2 个配对（尽管这里的 n=4 且实际只会有一个唯一配对）。通常，空间复杂度取决于实际配对的数量，但在这种寻找两数之和问题的场景下，最大空间复杂度期望为 O(n)（考虑一个极端情况，每个元素都不同且正好有一对应的配对使其和为目标值）。

综上所述，对于这个问题实例：

  • 时间复杂度为 O(n)。
  • 空间复杂度也为 O(n)。

它仅需一次遍历就能解决问题，且额外空间需求与输入数据量成正比，非常适合处理大量数据的情况。
