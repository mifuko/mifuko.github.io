Git更新hexo博客两次弹出登录框仍然登陆失败

发表于2024-03-07|更新于2024-03-07|mifukoIO
|字数总计:180|阅读时长:1分钟|阅读量:

更新hexo博客内容，执行hexo g -d报错，弹出两次登录框

起因是github把password换成了token

参考 github开发人员在七夕搞事情：remote: Support for password authentication was removed on August 13, 2021._github remote support for password authentication -CSDN博客

获取自己的token

打开personal settingg

左侧developer settings

选Personal access tokens，然后生成Generate new token

选择生效时间和权限

生成后需要复制，不会再看到第二次

重新执行hexo g -d，还是有两次登录框，在密码的地方输入token
