This course covers the fundamental concepts and technologies behind computer networks. It explains the layered architecture, starting from the physical layer that deals with transmitting raw data, up to the application layer protocols that enable services like the web, email, and file transfer. Key areas include data link protocols for reliable communication, the Internet Protocol and routing principles that form the network infrastructure, and transport protocols like TCP that enable end-to-end communication between applications. The course also highlights important network services like DNS for naming, as well as security aspects like firewalls and intrusion detection systems.

Here is an even more detailed overview of computer networks:

Computer Networks

Physical Layer

  • Data communication system models
    • Source system (information source, transmitter)
    • Destination system (receiver, destination)
  • Channel multiplexing techniques
    • Frequency division multiplexing (FDM) - different frequencies for users
    • Time division multiplexing (TDM) - time slots for users
    • Wave division multiplexing (WDM) - multiple optical signals on one fiber
      • WDM, Dense WDM (DWDM)
  • Wired broadband access technologies
    • Asymmetric DSL (ADSL) - more bandwidth downstream over phone lines
    • Fiber to the Home (FTTH) - end-to-end fiber to residences
      • Optical Line Terminal (OLT), Optical Network Units (ONUs)

Data Link Layer

  • Point-to-point communication
    • Point-to-Point Protocol (PPP) - framing, link control protocol
  • Broadcast communication
    • Network topologies - star, ring, bus (traditional Ethernet)
    • CSMA/CD protocol - carrier sensing, collision detection
  • Framing, error detection
    • Framing - encapsulating data into frames with headers/trailers
    • Error detection using Cyclic Redundancy Check (CRC)
    • Byte stuffing for transparent data transmission

Network Layer

  • Internet Protocol (IP)
    • IP addressing (IPv4 address classes A/B/C, subnetting)
    • Supporting protocols - ICMP, ARP
  • Routing protocols
    • Interior Gateway Protocols (IGPs)
      • RIP (distance vector)
      • OSPF (link state)
    • Exterior Gateway Protocol
      • BGP (path vector protocol for interdomain routing)

Transport Layer

  • User Datagram Protocol (UDP)
    • Connectionless, unreliable datagram delivery
    • Used by DNS, SNMP, TFTP, etc.
  • Transmission Control Protocol (TCP)
    • Connection-oriented, reliable byte stream transfer
    • Flow control via sliding window
    • Error control via sequence numbers, ACKs, retransmissions
    • Selective ACK (SACK), congestion control

Application Layer

  • Domain Name System (DNS)
    • Hierarchical domain name structure (root, TLDs, domains)
    • Name servers (root, TLD, authoritative)
    • Resolution process (recursive, iterative queries)
  • File transfer protocols
    • FTP (file transfer protocol) - interactive file access
    • TFTP (trivial FTP) - simple file transfer over UDP
  • Electronic mail
    • Mail user agents, mail servers
    • SMTP (mail transfer), POP3/IMAP (mail access)

Network Security

  • Security threats
    • Passive threats (eavesdropping)
    • Active threats (modification, spoofing, malware, DoS/DDoS)
  • Firewalls
    • Packet filtering (at network/transport layer)
    • Application gateways (with application data inspection)
  • Intrusion detection systems (IDS)
    • Signature-based (attack pattern matching)
    • Anomaly-based (profiles of normal behavior)
