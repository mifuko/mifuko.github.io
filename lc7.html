leetcode小抄：21. Merge Two Sorted Lists

You are given the heads of two sorted linked lists list1 and list2.

Merge the two lists into one sorted list. The list should be made by splicing together the nodes of the first two lists.

Return the head of the merged linked list.

Example 1:

Input: list1 = [1,2,4], list2 = [1,3,4] Output: [1,1,2,3,4,4]

Example 2:

Input: list1 = [], list2 = [] Output: []

Example 3:

Input: list1 = [], list2 = [0] Output: [0]

Constraints:

  • The number of nodes in both lists is in the range [0, 50].
  • -100 <= Node.val <= 100
  • Both list1 and list2 are sorted in non-decreasing order.

solution 1 聪明方法

用指针

实际上不需要对链表进行排序操作，因为两个链表已经是排序好的。解决这个问题的高效方法是直接合并这两个链表，同时保持排序。

mergeTwoLists 方法接收两个链表的头节点 list1 和 list2，并返回合并后的新链表的头节点。通过使用哑节点 dummy，我们可以简化合并过程中对头节点的处理，使得逻辑更加清晰。

关键数据结构 链表

  • 链表特性：链表是一种动态数据结构，每个节点包含数据和指向下一个节点的指针。对于有序链表来说，每个节点的值都小于或等于其后续节点的值。

  • 问题需求：题目要求合并两个已排序的链表，并保持合并后的链表也是有序的。这意味着新链表中的每个节点值都需要小于等于其后面的节点值。

关键数据结构 链表 用法说明

核心思路

  • 使用哑节点：引入一个哑节点（dummy node）作为新链表的起点，这样做可以简化操作，避免在合并开始时对头节点的特殊处理。哑节点的下一个节点（dummy.next）最终会指向合并后链表的实际头节点。

  • 双指针遍历：设置两个指针 p1 和 p2 分别指向两个链表的头部。通过比较这两个指针所指向节点的值，决定哪个节点应该先被添加到新链表中。这样可以保证新链表的排序性质。

  • 逐步构建新链表：每次选择值较小的节点加入新链表，并将对应的指针向前移动。这个过程持续到至少有一个链表被完全遍历完。

  • 处理剩余节点：当一个链表遍历完后，直接将另一个链表剩余的部分链接到新链表的尾部。这是因为剩余链表中的所有节点都已大于当前新链表的末尾节点（根据排序性质），可以直接追加。

  • 返回结果：最后返回哑节点的下一个节点，即新链表的头节点。
